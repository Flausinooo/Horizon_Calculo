# Projeto Horizon

## Descrição

O Projeto Horizon é uma solução voltada para a agricultura espacial, com foco na análise de substratos para futuras plantações em ambientes semelhantes aos encontrados na Lua.

## Objetivo

Comparar diferentes substratos e identificar qual apresenta melhor desempenho em relação à retenção de água e viabilidade para cultivo.

## Tecnologias Utilizadas

* Python
* Matemática Aplicada
* Modelagem Matemática

## Funcionalidades

* Cálculo da retenção de água.
* Cálculo do Índice de Viabilidade do Substrato Espacial (IVSE).
* Classificação dos substratos em:

  * Promissor
  * Aceitável
  * Inviável

## Estrutura do Código

* `calcular_retencao()`: calcula a porcentagem de água retida.
* `calcular_ivse()`: calcula o IVSE.
* `classificar_substrato()`: classifica o substrato de acordo com o resultado obtido.

## Resultado

O sistema analisa os dados fornecidos e apresenta a retenção de água, o IVSE e a classificação final do substrato.
